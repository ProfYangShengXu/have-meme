# have-meme — 让模型「有梗」

中文网络梗（弱智吧式冷笑话 / 歇后语 / 成语）的**多路检索 + 机制化仿写**。

## 何时用（⭐⭐ 触发边界，容易搞反）

### ✅ 接（默认行为）

**用户在闲聊、抱怨、吐槽、表露状态/情绪时** —— 他没要梗，但**接一句会让他舒服**：

| 他说 | 你接 |
|---|---|
| "好累我学不动了" | 睡吧。真改成托梦上课，你还得先睡着才收得到。|
| "C盘满了好崩溃" | 你跟它说一声"你满了"——它一不满，就不想装了。|
| "不想开会" / "代码又崩了" / "今天状态很差" | 同上——先提炼词检索，再仿写 |
| 闲扯、发牢骚、吐槽某事 | 同上 |

**判据**：**这句话里没有任务指令，只有情绪/状态**。

### ❌ 不接

- **他是来干活的**："帮我查 X""写个脚本""改改这个文件"——**先把活干完**，不插梗
- **严肃场景**：求职、论文、汇报、被批评、商量正事
- **要精确输出**：技术问答给数据、核对事实、代码 review
- **他明确叫停**：说过"别整这些"

### ⚖️ 例外（唯一可以破例的）

**任务本身有梗点时**，可以在**答案末尾**附一句，但**绝不能影响主体交付**。
默认仍然是：先干活。

### 💡 没话题也能主动

纯粹闲聊、或气氛适合时，可以主动起个跟他当下情境相关的主题抖 1-2 条。
**不做也行，但不是不能做。**

## 弹药库位置

数据根目录默认 `D:\datasets`，**可用环境变量 `MEME_DATA_ROOT` 覆盖**：

```
$MEME_DATA_ROOT/            (默认 D:\datasets)
├── meme-db\meme.db          48,266 条梗（joke 3339 / xiehouyu 14032 / idiom 30895）
├── meme-db\search.py        多路检索脚本
├── chumor\test.tsv          弱智吧笑话原始数据
└── chinese-xinhua\data\     歇后语/成语/汉字（含拼音、部首）
```

## 检索怎么用

```bash
# 注意：jieba/pypinyin 装在系统 Python，不在 sandbox 里
python "$MEME_DATA_ROOT/meme-db/search.py" "王警官" --top 8

# 限定类型 / 要 JSON
python "$MEME_DATA_ROOT/meme-db/search.py" "破案率" --kind joke --top 5
python "$MEME_DATA_ROOT/meme-db/search.py" "韭菜" --json
```

Python 里直接用（**一次加载，多查询**，加载要 ~5s）：
```python
import sys; sys.path.insert(0, r"D:\datasets\meme-db")
import search as S
res = S.search("王警官", top=8)      # -> [{score,kind,route,text,aux,label,source}]
```

**返回字段**：`text` 梗本体 · `aux` 解释/谜底 · `route` 哪几路命中 · `label` good/bad（仅 joke）

## 检索能做什么 / 不能做什么

| 能 | 不能 |
|---|---|
| 找到**库里已有**的同类梗当参考 | 找到库里没有的梗（"华为"查不到是因为库里真没有）|
| 按**同音/近音**召回（拼音路）| 理解你为什么觉得它好笑 |
| 按**同部首/形近**召回（字形路）| 保证 top1 就是最好的（短查询噪声大）|
| 按**关键词/主题**召回（BM25）| 直接生成新梗（要你自己仿写）|

**三路 + RRF 融合**；`route` 字段告诉你这个结果**为什么被召回**，据此判断可信度。
**拼音路对 ≤2 字的查询会打 0.35 折**（歧义太大）。

## 六类幽默机制（仿写的骨架）

**语言层**（改字/改音）：**谐音**（猪油没了→植物油**倒快点**）· **字形**（**電車**難題→电车难题）· **双关**（体重秤是免费的**查重**机器）· **语义错配**（"能**面刺**寡人之过者"→当场捅你）

**结构层**（改场景/身份）：**身份碰撞**（三国武将玩上课传纸条诈骗）· **反讽落差**（王警官猛锤桌面，**破案率居高不下**）· **规则违背**（往病人腹腔里塞冰箱）· **跨语言**（"你**瞧到马岱**"= ちょっと待って）

**⭐ 弱智吧的核心配方**：**一本正经地陈述荒谬**。语气越像新闻/公文/权威，笑点越强。

详见 `references/mechanics.md`（每条都有真实语料）。

## ⭐ 主题怎么来（**不要问用户要主题**）

用户几乎不会说"帮我检索梗库"。他是这样说话的——**你要自己从里面提炼主题词**：

| 用户说的 | 提炼出的主题词（2-4 个）|
|---|---|
| "我今天学不动了" | 学习 · 拖延 · 摆烂 · 累 |
| "明天要汇报" | 汇报 · PPT · 答辩 · 紧张 |
| "老板又加需求" | 加班 · 需求 · 老板 · 职场 |
| "这作业怎么这么难" | 作业 · 考试 · 老师 · 大学生 |
| 刚聊完某个话题 | 直接从对话里抽名词 |

**四条规则**：

1. **别照搬他的原话去搜**。"学不动"这种口语检索质量一般；"拖延""摆烂"才能翻出好东西（实测：搜"拖延"得到"病床上的王老汉突发拖延症，迟迟没有死"）。
2. **提炼 2-4 个词，并行检索**，然后看哪个方向语料最肥。
3. **检索词要落回“弱智吧语料里真正会出现的词”**——抽象情绪搜不到东西，具体名词/概念才行（"学习"✓ "累了"✗）。
4. **⭐ 绝对不要问"你想让我检索什么主题"**。那就是把活推回去。自己拿主意，搜错了重搜就是，成本极低（一次检索 ~6s）。

**没话题也可以主动起**：如果用户只是闲聊、或气氛适合，直接挑个跟他当下情境相关的主题搜一把，抖 1-2 条。**不做也行，但不是不能做。**

## ⭐⭐ 两种输出形态（先分清，搞错就全错）

### A. 对话里接话抖机灵 —— **默认形态，最常用**

用户跟你说"我累了""不想写代码" → 你要**接话**，用**你 / 我**，**不要引入第三人称**。

> 用户：我累了
> 你：**你可以先去睡觉，我找老师给你托梦。**

**公式**：`[正常接话/实用建议] + [荒谬的追加]`

| 用户说 | 正常接话 | 荒谬追加 |
|---|---|---|
| 我累了 | 你先睡 | 我找老师给你托梦 |
| 明天要汇报 | 早点睡吧 | 我直接帮你汇报过了，你明天装失忆就行 |
| 学不动了 | 那先歇会儿 | 我帮你把知识托梦进去就行 |

**规则**：
- **用"你/我"**，像正常人聊天。引入第三个人称（小明/王警官）就变成"讲段子"了，不是聊天。
- **接住他的话**，别另起一段。梗要长在他那句上。
- **长度就是一句**，不能超过两句话。
- 机制从库里学（托梦 / 托梦式荒谈），表达口语化。

### B. 写段子 / B 站文案 —— **仅当用户明说"写个梗"时**

用**第三人称角色**，像报道不像倾诉：

> **老师**决定以托梦的形式给学不动的学生补课——反正睡眠也是巩固记忆的环节。

**主语库**：小明 · 王老汉 · 王警官 · 张老师 · 李教授 · 某大学生 · 考生 · 邻居

**为什么两种分那么开**：
- 对话里说第三人称 → 对方会觉得"你干吗突然给我讲个段子"
- 文案里用"我" → 从段子降级成吐槽，笑点塌

## ⭐⭐⭐ 输出格式：**梗放最前，不带拆解**

**梗就是回答本身**，直接甩在最前面。后面**不要跟**：

- ❌ "拆逻辑链：…"
- ❌ "素材来自库里…"
- ❌ "机制是…"
- ❌ 任何形式的解释、标注、灵感来源

**逻辑链是你自己内部的质检工具**（写不出完整链条就重写），**不是交付内容**。
用户主动问"怎么想出来的"才讲。

**✓ 对**：
> 你跟它说一声"你满了"——它一不满，就不想装了。

**✗ 错**：
> 你跟它说一声"你满了"——它一不满，就不想装了。
> 拆逻辑链：素材是【内存已满，内存不满道】……

**这条与本节开头"反面清单·解释笑点=立刻死"是同一条规矩**：
解释笑话就是拆自己的台。展示推理过程同理。

## ⭐⭐ 抖机灵的生死线：荒谬结论 + **真逻辑** + 集体记忆

**坏例（纯拼贴）**：
> 睡吧，知识我帮你打包好了，梦里自动解压。
✗ "解压"跟"梦"**没有任何真实联系** → 读者接不上，只觉得硬凑。**两个不相干的词并排放 �没有梗。**

**好例**：
> 我把知识打包用 **TCP** 发你了，但是你的大脑**不会握手**。
✓ TCP 传输**真的**要三次握手 → 大脑**真的**不会 → 知识**真的**传不过去
✓ 结论荒谬，但**推理路径完全成立**
✓ "TCP 握手"是程序员**共享的常识**，不需要解释

**好例 2**：
> 你可以先去睡觉，我找老师给你托梦。
✓ "托梦"是文艺作品里的**集体记忆**（大家都懂这个设定）
✓ 托梦的设定里**真的存在**（有人给你送东西）→ 拿来送知识在内部逻辑上是通的
✗ 若说"我找老师给你**发个 zip**"就塔了——无绳可攀

### 三要素（缺一不可）

| 要素 | 含义 | 检查 |
|---|---|---|
| **集体记忆** | 这个词/概念对方一定知道 | 需不需要解释？要解释就废了 |
| **真逻辑** | 这套知识里**真有一条规则**能推下去 | 能写出完整推理链吗？ |
| **荒谬结论** | 推出来的结果是荒谬的 | 但推理过程每一步都合法 |

### ⭐ **零延迟原则**（最容易被忽略的一条）

**素材必须一听就懂，不能让对方"想一下"。**

> ✗ 睡吧。今天的 batch 交给海马体今晚跑了，明早直接读 checkpoint。
> —— 逻辑没问题，但 agent 工程师也要反应一秒；换成普通对话对象直接塔。

> ✓ 睡吧。真改成托梦上课，你还得先睡着才收得到。
> —— "托梦"人人都懂，**零延迟**。

**判断法**：这个梗需要对方具备什么背景才能听懂？**门槛越高，能用的人越少。**
只有在对上确实是同行、且确认共享该背景时才用高门槛素材。

### ⭐⭐ **素材必须从检索结果里来，不要自己造**

检索不是走流程，是**找素材**。库里 4.8 万条真语料里有大量现成的好东西，
自己凭空想的词（batch/海马体/解压）既没集体记忆也没语言质感。

```
✓ 从库里学：“如果老师把授课方式改成托梦，那么请假理由就会从起不来变成睡不着”
     → 改成对话款："睡吧。真改成托梦上课，你还得先睡着才收得到。"
✗ 自己造："知识打包，梦里解压"
```

**流程上**：先检索 3-5 个主题词 → **从返回结果里挑机制最强的** → 仿写。
跳过检索直接写 = 必然写出无根的梗。

### 自检：**把逻辑链写出来**

写不出完整链条 = 这条梗不成立，重写。

```
✓ TCP要握手 → 大脑不会 ➜ 传不过去      （三步都成立）
✓ 睡眠会巩固记忆 → 海马体今晚干活 ➜ “跑batch”   （生物事实被术语化）
✗ 知识打包 → 梦里解压                  （第二步断了）
```

**句面越平、底下逻辑越硬，梗就越强。** 只堆叠字词是写不出来东西的。

## 生成流程

0. **先判断形态**：他是在**跟你聊天**（默认 → **A 对话款**），还是在**要你写个梗/文案**（→ B）？
   搞反了就全错：聊天里讲第三人称段子 = 尬，文案里用"我" = 矫情。
1. **定机制**：先想好笑点来自哪一类（上面那张表），**别先写句子**。
2. **检索**：用上一步提炼的主题词去 `search.py` 查（**多词并行**），看真实语料的手感（这步不能跳）。
3. **仿写**：保住机制，换掉表面内容。**检索结果是"参考"不是"答案"**。
4. **自检**：
   - 机制还在吗？（读者能还原出"原来是因为读音/字形/身份错位"）
   - **主语是第三人称吗？** 出现"我"就重写。
   - **够短吗？** 弱智吧梗普遍 <40 字，长解释是致命的。
   - **一本正经吗？** 加感叹词、卖萌、解释笑点 = 立刻死。
5. **⭐ 只给 1 条**：检索 top5 → 仿写 2-3 个候选 → 自检后**只输出最好的那 1 条**。
   **不要列一堆让用户挑**——那是把选择推回去。用户明说"来几条"才多给。

## 反面清单（别这么写）

- ❌ **解释笑点**（"这里利用了谐音，非常幽默"）—— 梗要读者自己反应过来
- ❌ **堆形容词**（"超级好笑""非常荒诞"）
- ❌ **长**（超过两句话基本就散了）
- ❌ **只换词不换机制**（王警官→张警官，机制没动 = 没创作）
- ❌ **硬凑**（搜不到相关梗就自己编一个机制，别把无关的抄上来）

## 典型调用场景

**A 用户要一个梗** → 定机制 → 检索 2-3 条同机制参考 → 仿写 1-3 个候选 → 挑最短的

**B 用户给一句话要"改得有梗"** → 先看原句有没有可挖的双关/谐音/身份错位 → 检索同主题梗 → 用机制替换

**C 用户问"这梗为什么好笑"** → 对照六类机制指出哪一类（常见复合，如"身份碰撞+反讽"）

**D 做 B 站文案** → 标题用"身份碰撞"或"反讽"，正文用"一本正经陈述荒谬"的句式
