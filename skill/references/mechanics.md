# 幽默机制详解（含真实语料）

## 一、语言层（改字 / 改音）

### 1. 谐音 Homophonic
读音相同或相近，意义完全跑偏。
- 家里的猪油没了，小明只能把植物油**倒快点**当猪油用了
- 曹操问夏侯惇瞧到了什么，夏侯惇说：**瞧到马岱**（≈ 日语 ちょっと待って）
- 东北人认为**银杏**这种东西是逐渐发烂发臭的（性本善 / 性本恶 / 银杏）

**仿写要点**：先在目标句里找一个**能被听错的词**，再去读音表里找同音词。
查读音：`D:\datasets\chinese-xinhua\data\word.json`（汉字带 pinyin）

### 2. 字形 Glyph
拆字、繁简、部件重组。
- 我把**電車**難題简化了，现在是**电车**难题

**仿写要点**：繁体字是天然素材（言/訁、车/車、马/馬）。
查部首：`word.json` 的 `radicals` 字段

### 3. 双关 Pun
同一个词两种读法都成立。
- **体重秤是免费的查重机器**
- 老师：请用"布置"一词造句。小明：你不知道**谐音梗扣钱**吗？

### 4. 语义错配 Semantic Mismatch
把词按字面义硬解。
- "能**面刺**寡人之过者，受上赏" → 元老院当场刺杀凯撒
- "**六神无主**！" 因为偷窃花露水而被拘留的小偷大声狡辩

## 二、结构层（改场景 / 身份）

### 5. 身份碰撞 Identity Collision（弱智吧最常见的配方）
把 A 的身份 / 规则套进 B 的场景。
- 三国武将玩"上课传纸条"诈骗（古代谋士被现代小套路拿捏）
- **李白**：根据犯人李白的微信步数，衙门推断出连环凶杀案的受害者数量
- **王警官**系列："经验丰富的王警官经过缜密分析，终于判定被害人在死亡之前还活着"

**关键**：**角色要保持自己的身份口吻**，只让场景错位。

### 6. 反讽 / 预期落差 Irony
- 王警官一生气就用拳头猛锤桌面，**破案率居高不下**
- 扫黄行动刚开始，经验丰富的王警官就把所有违法店铺列了出来

**关键**：把两个不相关的事**用因果词硬连**（所以 / 终于 / 因此），落差自己就出来了。

### 7. 规则违背 Rule Violation
公然违反常识，且**不解释**。
- 趁其他医生不注意我偷偷往病人腹腔里塞了台冰箱再面不改色地缝好
- 警队创新为独臂歹徒推出**单环手铐**

## 三、歇后语的用法（另一种武器）

歇后语天然是"**前半句设局 + 后半句抖包袱**"，结构与梗图高度同构。库里有 14,032 条。
- 做贼的说梦话 → 想偷
- 看见麦苗叫韭菜 → 不识货

**用法**：直接引用显得老派；**拆它的结构**（设局→反转）来仿写更现代。

## 四、生成时的三条铁律

1. **选机制先于造句**。想不出机制 = 这条梗还不存在。
2. **一本正经地陈述荒谬**。句式越像新闻 / 公文 / 权威通告，反差越强。
3. **短**。弱智吧高赞普遍 <40 字。解释笑点 = 自杀。
